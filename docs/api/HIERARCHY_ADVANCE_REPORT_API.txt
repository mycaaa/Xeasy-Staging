================================================================================
HIERARCHY-BASED ADVANCE REPORT API - FINAL DOCUMENTATION
================================================================================

OVERVIEW:
This API provides advance payment reports based on employee hierarchy levels.
Uses recursive employee fetching based on RepEmployeeID from hrm_employee_general.

BASE URL: /api/advance/hod

================================================================================
STEP 1: CHECK EMPLOYEE LEVEL
================================================================================

Endpoint: GET /api/advance/hod/employee-level

Parameters:
- employee_id (required): Employee ID to check

Example Request:
GET /api/advance/hod/employee-level?employee_id=1225

Response:
{
  "success": true,
  "message": "Employee level retrieved successfully",
  "data": {
    "employee_id": 1225,
    "employee_name": "John Doe",
    "employee_code": "1095",
    "access_level": "zone",
    "level_description": "Zone Level"
  }
}

Access Levels:
- "territory" = Territory Level (TerrId > 0)
- "region" = Region Level (RegionId > 0, TerrId = 0)
- "zone" = Zone Level (ZoneId > 0, RegionId = 0, TerrId = 0)
- "bu" = Business Unit Level (BUId > 0, ZoneId = 0, RegionId = 0, TerrId = 0)
- "all" = All Levels Access (BUId > 0 with other levels)
- "none" = No hierarchy assigned

================================================================================
STEP 2: LOAD APPROPRIATE FILTERS BASED ON LEVEL
================================================================================

2.1 BUSINESS UNIT LEVEL (access_level = "bu")
----------------------------------------------
Show Filter: Business Units dropdown only

API: GET /api/advance/hod/business-units
Parameters:
- search (optional): Search term
- limit (optional): Default 10

Example:
GET /api/advance/hod/business-units?search=sales&limit=10

Response:
{
  "success": true,
  "data": [
    {
      "id": 5,
      "name": "Sales Division",
      "code": "SD",
      "numeric_code": "001"
    }
  ]
}

Report API Call:
GET /api/advance/hod/consolidated-report?employee_id=1225&bu_id=5&month=2&year_id=2026

---------------------------------------

Step 1 - Get Business Units:
GET /api/advance/hod/business-units?search=&limit=10

================================================================================
FILTER LOGIC SUMMARY
================================================================================

Employee Level → Available Filters → Report Parameters
-------------------------------------------------------

BU Level:
- Filters: BU only
- API: ?employee_id=X&bu_id=Y

Zone Level:
- Filters: BU → Zone
- API: ?employee_id=X&bu_id=Y&zone_id=Z

Region Level:
- Filters: BU → Zone → Region
- API: ?employee_id=X&bu_id=Y&zone_id=Z&region_id=R

Territory Level:
- Filters: BU → Zone → Region → Territory
- API: ?employee_id=X&bu_id=Y&zone_id=Z&region_id=R&terr_id=T

All Level:
- Filters: BU → Zone → Region → Territory (all available)
- API: ?employee_id=X&bu_id=Y&zone_id=Z&region_id=R&terr_id=T

None Level:
- No filters available
- Show error message

================================================================================
CASCADING FILTER BEHAVIOR
================================================================================

1. When BU is selected → Load Zones for that BU
2. When Zone is selected → Load Regions for that Zone
3. When Region is selected → Load Territories for that Region
4. Each dropdown filters the next level
5. Search is available in all dropdowns (limit: 10 records)

================================================================================
IMPORTANT NOTES
================================================================================

1. All APIs use recursive employee fetching via RepEmployeeID
2. Only PAID advances are shown in reports (payment_status = 'Paid')
3. Team members list shows only employees with advance requests
4. Access level is returned in all responses for UI logic
5. Hierarchy filters are optional - can get report without filters
6. Month filter: 1-12 (Jan-Dec)
7. Year filter: Use year_id (e.g., 2026)
8. All dropdowns support search with 10 record limit

================================================================================
COMPLETE WORKFLOW EXAMPLE
================================================================================

Step 1: Check Employee Level
GET /api/advance/hod/employee-level?employee_id=1225
→ Response: access_level = "zone"

Step 2: Load Filters Based on Level
GET /api/advance/hod/business-units?limit=10
→ User selects BU: id=5

GET /api/advance/hod/zones?business_unit_id=5&limit=10
→ User selects Zone: id=12

Step 3: Get Team Members (Optional)
GET /api/advance/hod/team?employee_id=1225
→ Shows all team members with advances

Step 4: Get Report with Filters
GET /api/advance/hod/consolidated-report?employee_id=1225&bu_id=5&zone_id=12&month=2&year_id=2026
→ Shows filtered report
